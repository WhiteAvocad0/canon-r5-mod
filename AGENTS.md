# Canon R5 Mod

Public source-preview project for original Canon EOS R5 firmware `2.2.1` only. Provides two separate offline-buildable profiles:

1. `shutter-feedback` (default): custom startup + shutter WAV speaker playback; immutable private reference is user-confirmed `build36` (`562,144` B, `3579cecf...`).
2. `xpan-crop` (experimental, silent — no audio): `2.71:1` (`512:189` ~ `2.709:1`) XPan crop mode (`8192x3024` Large JPEG, `8192x5464` CR3 crop `(0,1220,8192,3024)`, replaces `16:9`, Q `"XPan"` label, live LCD/EVF framing, playback masking). Prior private candidate `466ca8fe` (`c9f06053`) was user-confirmed on rear LCD landscape first-open playback (`DbgRA127`), live LCD/EVF, Q label, and saved crop output; earlier `128 GB` silent XPan (`1b7bfcfa`) + CFexpress coexistence was also confirmed; latest native reference `4838eb81` (`427bb28d`, `117` inputs, `31` hooks, `17` pages, `8` L2 tables, `120` witnesses, `948,152` free bytes, `184`B fit / `40`B view owner, `67` V1 reasons) extends playback masking to `(device in {0,1}, orientation in {0,2}, effective r7=0)` and was reported working in the owner's four-case normal ▶ session on 17 November 2026 (private research suite: `289` tests and independent reviews). Automatic rear-LCD instant review still briefly shows a 16:9 guide first. The public repackaged image is hardware-untested.

Preserve native baseline C/ASM/linker behavior across both profiles and clearly distinguish source facts, host tests, private hardware baselines, and hardware-untested public repackaged builds.

- Use `rtk` when already available; otherwise run the documented commands directly. Do not install it merely to follow this guide.
- Distinguish source facts, host tests, and user-reported camera evidence. Neither public repackaged build (`shutter-feedback` or `xpan-crop`) has itself been hardware-tested. Private `build36` (`shutter-feedback`) was user-confirmed for XP startup, Mambo shutter, and normal shooting on `16 GB` SDHC/FAT32 and full-capacity `128 GB` SDXC/exFAT (SDXC returned files, repeated boots, and longer shooting unverified). Private `xpan-crop` (`466ca8fe`) was user-confirmed for rear LCD landscape first-open, live LCD/EVF, Q label, and `RAW+Large JPEG` XPan capture; `4838eb81` normal ▶ portrait LCD/EVF playback was reported working in the four-case session on 17 November 2026; automatic rear-LCD instant review still has a reported guide flash. Public repackaging and other qualities/modes/active auto-rotation remain unverified/declined.
- Do not commit or upload Canon ROM/FIR/dumps, built images/objects/toolchains, real diagnostic dumps/photos (`.CR3`/`.JPG`), user audio (XP/Mambo), generated Canon ROM pages/tables/vectors, credentials, build outputs, private lab history, or local plans. Users supply their own ROM dump (and two WAV clips for `shutter-feedback`). Publication is source+docs only, no binary release.
- Preserve native baseline C/ASM/linker behavior. All addresses are original R5 `2.2.1`-specific. Other R5 firmware/R5 C/R5 Mark II/R6/R6 II/R6 III are unsupported and need independent ports; no cross-model binary testing.
- No automatic camera-side bootflag activation, firmware/NVRAM writes, raw-device writes, or formatting. Card instructions require backups and correct model/firmware; supplied tools build offline only.
- Firmware admission must accept per-camera settings differences outside immutable target code while retaining strict exact-code/patch/table/resource checks (`config/target_contract.json`, `config/xpan_target_contract.json`). Preserve actual caller ROM digest and paths as provenance, not a private camera full-dump hash as compatibility identity. Derive ROM-backed XPan inputs (`target-page.bin`, `frame_row_constants.h`, `menu-vector.bin`, `feature-targets.h`) into `--output` only after strict target admission. No `--force` or skip-target-check option.
- Audio roles (`shutter-feedback` default): startup WAV and shutter WAV separate, full clips, 48kHz mono 16-bit PCM, 32-byte zero alignment only, no normalization/trimming. Busy effects drop; no delayed replay. No immediate user mute or full burst/movie/latency/shutdown certification claimed.
- XPan role (`--profile xpan-crop`): intentionally silent (`R5_CROP_ONLY=1`), forbids `--startup-wav`/`--shutter-wav`, links zero PCM/puff symbols, disables added shutter playback (`play_shutter = 0`) while retaining the headless control/report worker. Do not remove that worker; it maintains MMU/report state. Canon's own Beep setting is unchanged.
- Maintain GPL-2.0-or-later notices from Magic Lantern-derived boot/footer work; no Canon affiliation or endorsement. Do not attest human review or broader device support.
- Portable documented CLI:
  - Audio (default): `python3 tools/build.py --rom PATH --startup-wav PATH --shutter-wav PATH --toolchain DIR --output DIR`
  - Silent XPan: `python3 tools/build.py --profile xpan-crop --rom PATH --toolchain DIR --output DIR`
  Outputs ignored under `build/` by convention. CLI never contacts camera/media.
- Host tests must run without private lab paths/assets or ARM toolchain. Real-ROM cross-build verification is separately opt-in and reported distinctly. Do not install unrelated software or dependencies automatically.
