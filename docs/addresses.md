# EOS R5 `2.2.1` Typed Address & Binding Reference

All addresses on this page apply **exclusively to the original Canon EOS R5 on firmware `2.2.1`**. Do not reuse these addresses on other R5 firmware versions, R5 C, R5 Mark II, or any R6-family body.

> [!IMPORTANT]
> **Keep Address Types Separate**
> - **ROM Thumb entry (odd address, bit 0 = 1)**: Executable Thumb target address in `0xE0000000..0xE3FFFFFF` (for example `0xE08B1971`).
> - **ROM base / data window (even address)**: Non-Thumb base or checksum boundary (for example `0xE0100000`).
> - **Fixed RAM slot**: Fixed RAM address holding a pointer or state struct in Canon's `2.2.1` memory map.
> - **Field offset**: Byte offset added to a dereferenced RAM object pointer.
> - **Property ID**: 32-bit Canon property identifier passed to the property observer.
> - **Private resident symbol**: Address inside `0x001994B0.._reserved_end` generated by the linker. **Private resident addresses depend on your compiled code and audio clip sizes** — never treat `build36` example offsets as fixed ROM constants. Always inspect your own build's `symbols.json` and linker `.map`.

## 1. Boot, Image Convention, and ROM Guard

| Name | Value | Type | Role |
| --- | --- | --- | --- |
| `FW_ROM_BASE` | `0xE0000000` | ROM base (even) | Base of `64 MiB` (`67,108,864`-byte) ROM dump (`0xE0000000..0xE3FFFFFF`). |
| `FW_MAIN_START` | `0xE0100000` | ROM region (even) | Start of Canon main firmware block and `4,096`-byte copied startup slice (`0xE0100000..0xE0100FFF`). |
| `FW_SIGNATURE_WORDS` | `65536` (`0x10000`) | Count (`u32`) | `256 KiB` word count summed by the stage-0 ROM guard (`0xE0100000..0xE013FFFF`). |
| `FW_SIGNATURE` | `0x22C94093` (`583614611`) | Checksum (`u32`) | Required additive 32-bit little-endian word sum over `FW_SIGNATURE_WORDS` at `0xE0100000`. |
| `FW_AUTOEXEC_BASE` | `0x00800000` | Staging RAM address | Fixed load/link address where Canon's native `BOOTDISK` loader stages `autoexec.bin`. |
| `FW_CSTART_OFFSET` | `0xEC` (`236`) | Byte offset | Offset of `cstart` within the `4,096`-byte `copied_startup` block. |
| `FW_SECONDARY_SLOT` | `0xDFFC4FA0` | Fixed RAM/device slot | Secondary-core wait mailbox; secondary cores poll until primary core writes `0xE0100001` (`FW_MAIN_START + 1`). |
| `FOOTER_MAGIC` | `0xE12FFF13` | Image convention | Magic Lantern footer marker at `image_bytes - 8`, paired with a 32-bit word at `image_bytes - 4` making whole-image 32-bit LE XOR equal `0`. **This is an ML image-integrity convention, not Canon cryptographic authentication.** |

## 2. Canon User Pool & Resident Reservation Bounds

| Name | Value | Type | Role |
| --- | --- | --- | --- |
| `FW_USER_START` | `0x001994A8` | Fixed RAM address | Start of Canon `UserPool` checked by `create_wrapper`. |
| `FW_RESIDENT_BASE` | `0x001994B0` | Fixed RAM link base | Start of copied resident section (`_resident_start`), aligned 8 bytes after `FW_USER_START`. |
| `FW_USER_LENGTH` | `0x00112D70` (`1,125,744`) | Byte length | Total original Canon `UserPool` size checked by `create_wrapper`. |
| `FW_OBJECTS_START` | `0x002AC218` | Fixed RAM address | End of `UserPool` (`FW_USER_START + FW_USER_LENGTH`); `_reserved_end` must stay strictly below this address. |
| `FW_MINIMUM_USER_LEFT` | `0x00080010` (`524,304`) | Byte floor | Minimum Canon `UserPool` bytes that `create_wrapper` and the linker reservation guard must leave unallocated. |
| `FW_STARTUP_BYTES` | `4096` (`0x1000`) | Byte length | Size of the RAM-copied startup slice (`copied_startup`). |
| `FW_PRIVATE_STACK_BYTES` | `4096` (`0x1000`) | Byte length | Private stack size reserved at the end of `.bss` (`_private_stack_top == _reserved_end`), used during early `CamIF` polling before returning to Canon's init-task stack. |

| Name | Address / Value | Type | Role |
| --- | --- | --- | --- |
| `AUDIO_BEEP_START` (`SE_BeepStart`) | `0xE08B1971` | ROM Thumb entry (odd) | Stock `ABeep` playback submission entry (`(0, descriptor_ptr)`), shared by both Startup and Shutter roles (`OutSel = 0`). |
| `AUDIO_STATE_QUERY` | `0xE07F14DB` | ROM Thumb entry (odd) | Queries state-object handle readiness (`1` = ready, `-1` = invalid handle). |
| `WITNESS_SLEEP` (`sleep_ms`) | `0xE07F1703` | ROM Thumb entry (odd) | Stock millisecond sleep helper (`20 ms` poll sleep in audio and worker loops). |
| `AUDIO_SINGLETON_SLOT` | `0x00010230` | Fixed RAM slot | Pointer to `ABeep` singleton object (`+0x00` non-null, `+0x04` state handle, `+0x24` backend return, `+0x28` last PCM ptr, `+0x2C` last PCM bytes, `+0x48` phase [`1` active, `2` stopped/interrupted, `3` settled], `+0x4C` stock test-owner flag). |
| `AUDIO_AUDIOCTRL_SLOT` | `0x00010234` | Fixed RAM slot | Pointer to `AudioCtrl` object; `+0x04` (`AUDIO_AUDIOCTRL_HANDLE_OFFSET`) holds the state-object handle queried via `0xE07F14DB` (must equal `1`). |
| `AUDIO_AUDIO_IC_SLOT` | `0x00010240` | Fixed RAM slot | Pointer to `AudioIC` object; `+0x04` (`AUDIO_AUDIO_IC_INIT_OFFSET`) is the initialized flag (must equal `1`). |
| `AUDIO_OUTPUT_CONTEXT_SLOT` | `0x00019140` | Fixed RAM slot | Output context pointer (must be non-null). |
| `AUDIO_ICU_CACHE_BASE` | `0x00019158` | Fixed RAM struct | ICU cache state: `+0x00` kind (`0` = `VAIF`, `1` = `AK`), `+0x04` initialized flag (must be non-zero). |
| `AUDIO_VAIF_PARAM_SLOT` | `0x00028C84` | Fixed RAM slot | Direct parameter pointer checked when ICU cache kind is `0` (`VAIF`; base `0x28C7C + 8`). |
| `AUDIO_AK_PARAM_SLOT` | `0x00028C78` | Fixed RAM slot | Direct parameter pointer checked when ICU cache kind is `1` (`AK`; base `0x28C70 + 8`). |

## 5. Worker Task Cores, Observer, and Release Counter

| Name | Address / Value | Type | Role |
| --- | --- | --- | --- |
| `create_task` (`RawCreateCore`) | `0xE047E975` | ROM Thumb entry (odd) | Non-asserting stock task-creation core (`stack = 4096`, `priority = 19`, `options = 0`, name `"r5shutter"`). Returns `-1` on failure or opaque `u32` handle (`[TCB + 64]`, including valid high-bit handles). |
| `start_task` (`start_task_core`) | `0xE047EA9F` | ROM Thumb entry (odd) | Starts created task by opaque raw task ID (`0` = ok; may preempt before returning). |
| `delete_task` (`delete_task_core`) | `0xE047E9F9` | ROM Thumb entry (odd) | Rollback teardown used **only** if `start_task` fails on a newly owned task. |
| `register_slave` | `0xE07F1FCB` | ROM Thumb entry (odd) | Asynchronous property-slave registration (`R5O2` observer). |
| `ack` | `0xE07F2575` | ROM Thumb entry (odd) | Property notification acknowledgment (`ack(token, property)`). |
| `debug` (`DebugMsg`) | `0xE080A2D5` | ROM Thumb entry (odd) | Stock debug logger (`class = 0x84` / `132`, `level = 3`) emitting `R5O2` summary and worker rows. |
| `OBSERVER_PUBLIC_SLOT` | `0x0000513C` | Fixed RAM slot | Public property-API readiness pointer checked by `observer_start` (`[0x513C]` and `[[0x513C]+4]` non-null). |
| `OBSERVER_COUNTER_CONTEXT_SLOT` | `0x0001259C` | Fixed RAM slot | Pointer to release-counter context object (`0` if unready/unobserved). |
| `counter_field_offset` | `+0x1A14` (`6676`) | Field offset | Byte offset (`0x1000 + 0xA14`) from dereferenced `[0x0001259C]` holding the saturating `u32` release counter polled every `20 ms` by the shutter worker. |
| Release property (diagnostic) | `0x12000003` | Property ID | Observed in `R5O2` diagnostics only; **not** the audio playback trigger. |
| Additional observed properties | `0x12000001`, `0x02050001` | Property IDs | Mechanical/job property IDs retained in `R5O2` diagnostic history. |
| `OBSERVER_BEEP_PROPERTY` | `0x80000023` | Property ID | Canon Beep setting property; toggling Beep triggers an `R5O2` diagnostic dump (does **not** mute the mod). |

## 6. Optional FIO Witness Bindings (Skipped in Default `shutter-feedback` Profile)

The default `shutter-feedback` profile branches directly to `witness_done` (`b witness_done`) and skips startup `B:/R5AUD001.TXT` file writes to avoid duplicate FAT directory entries on repeated boots. For diagnostic profiles that retain FIO witness output, `firmware.json` defines:

| Name | Address | Type | Role |
| --- | --- | --- | --- |
| `WITNESS_CREATE` | `0xE07E1F0B` | ROM Thumb entry (odd) | Stock file create (`B:/R5BOOT.TXT` or `B:/R5AUD001.TXT`). |
| `WITNESS_WRITE` | `0xE07E25F9` | ROM Thumb entry (odd) | Stock file write (requires uncached buffer view). |
| `WITNESS_CLOSE` | `0xE07E2D6F` | ROM Thumb entry (odd) | Stock file close. |
| `WITNESS_FLUSH` | `0xE07E40EF` | ROM Thumb entry (odd) | Stock drive flush (`B:/`). |
| `WITNESS_MOUNT_CHECK` | `0xE07E4861` | ROM Thumb entry (odd) | Stock drive mount readiness check (`B:/`). |
| `WITNESS_TO_UNCACHED` | `0xE04E1FE1` | ROM Thumb entry (odd) | Converts cached resident address to uncached alias (`addr | 0x40000000`) after `FW_CACHE_CLEAN`. |

## 7. Build-Dependent Resident Symbols (`build36` Baseline Examples ONLY)

> [!NOTE]
> The addresses below are **examples from the private `build36` baseline** (`562,144`-byte `autoexec.bin`, `474,816`B Startup PCM + `78,048`B Shutter PCM). Any change to your WAV lengths or source files shifts every symbol after `_resident_start`. Always read your own build's `symbols.json`.

| Symbol | `build36` Example Address | Meaning |

| `_resident_start` | `0x001994B0` | Fixed link base of resident section. |

| `audio_pcm` | `0x00199B60` | 32-byte-aligned Startup PCM buffer (`474,816` bytes in `build36`). |
| `shutter_descriptor` | `0x0020DA20` | 64-byte `ABeep` descriptor for Shutter WAV (`build36` example). |
| `shutter_pcm` | `0x0020DA60` | 32-byte-aligned Shutter PCM buffer (`78,048` bytes in `build36`). |
| `sound_boot_state` | `0x002226CC` | Boot/startup/context-check diagnostic state (`build36` example). |
| `sound_worker_state` | `0x00222C34` | Worker task handle, counters, and fault state in `.bss` (`build36` example). |
| `_reserved_end` / `_private_stack_top` | `0x00223CD0` (`2,243,792`) | End of resident reservation (`567,336` B reserved, leaving `558,408` B free `>= 524,304` B floor in `build36`). |
